# Chat Video Studio — موتور ساخت ویدیو با ChatGPT

**An independent, ChatGPT-first video rendering project, inspired by [CineCode](https://github.com/sarpstar/cinecode).**

بدون Claude و بدون کلید API مدل هوش مصنوعی. خود ChatGPT ایده، متن و صحنه‌ها را می‌سازد؛ این سرویس مستقل آن‌ها را به صورت ویدیو MP4 رندر می‌کند.

> **وضعیت:** نسخه آزمایشی 0.1؛ برای ساخت موشن‌گرافیک‌های ساده و اسلایدهای ویدیویی، نه تولید فیلم فوتورئال یا هم‌ارزی کامل با CineCode. اتصال واقعی ChatGPT نیازمند استقرار سرور و اضافه کردن آن به‌عنوان یک اتصال MCP است.

## قابلیت‌های فعلی

- متن فارسی (با شکل‌دهی راست‌به‌چپ توسط Pillow/RAQM در صورت وجود کتابخانه) و انگلیسی
- سه نسبت تصویر: 16:9 (`landscape`)، 9:16 (`portrait`)، 1:1 (`square`)
- قالب‌های `headline`، `stats` و `product` با رنگ‌بندی `midnight`، `light`، `sunset`
- ۱ تا ۱۰ صحنه، هر صحنه ۲ تا ۱۲ ثانیه، حداکثر ۶۰ ثانیه
- خروجی H.264 MP4 بدون صدا و PNG پیش‌نمایش، با حرکت جزئی دوربین
- ساخت و ویرایش استوری‌بورد، صف رندر تک‌کارگره، مشاهده وضعیت، لینک‌های دانلود یک‌ساعته
- ابزارهای MCP به نام‌های `create_storyboard`, `revise_storyboard`, `render_video`, `video_status`, `list_videos`
- بدون دانلود مدل، بدون API و سرویس صوتی بیرونی

## اجرای محلی

نیازمندی‌ها: Node.js 22، Python 3، Pillow، FFmpeg با libx264، یک فونت فارسی مانند Noto Sans Arabic.

```bash
cp .env.example .env
# دو مقدار STUDIO_TOKEN و MCP_ACCESS_PATH را با مقادیر تصادفی مستقل جایگزین کنید.
# در محیط Docker از تنظیم متغیرهای محیطی برای نگهداری امن اسرار استفاده کنید.
set -a; . ./.env; set +a
npm start
```

آزمایش‌ها:

```bash
npm test
python3 renderer/render.py examples/ravaj-intro.json /tmp/video-work /tmp/demo.mp4 /tmp/preview.png
```

## اجرای Docker / Railway

```bash
docker build -t chat-video-studio .
docker run --rm -p 8787:8787 \
  -e STUDIO_TOKEN="$(openssl rand -hex 32)" \
  -e MCP_ACCESS_PATH="$(openssl rand -hex 32)" \
  -e PUBLIC_BASE_URL="http://localhost:8787" \
  -v studio-data:/data chat-video-studio
```

توجه: دستور فوق کلیدهای تصادفی را تولید می‌کند اما چاپ نمی‌کند؛ برای اتصال ChatGPT باید **کلید مسیر همان استقرار** را به شکل امن ذخیره کنید. در استقرار عملی، دو کلید را پیشاپیش تولید کرده و در secrets محیط اجرای سرویس قرار دهید.

برای Railway سرویس Docker جدید بسازید، `STUDIO_TOKEN`، `MCP_ACCESS_PATH`، `PUBLIC_BASE_URL` (دامنه HTTPS واقعی) و `DATA_DIR=/data` را به‌عنوان متغیر محیطی تنظیم کنید و یک volume پایدار به مسیر `/data` وصل کنید. حداقل منابع پیشنهادشده به رزولوشن و مدت ویدیو وابسته است؛ از ویدیوهای کوتاه شروع کنید. برای استفاده عمومی چندکاربره، پیاده‌سازی OAuth، سهمیه‌بندی، ذخیره‌سازی ابری و صف مقاوم الزامی است.

## اتصال به ChatGPT

۱. سرور را با یک دامنه HTTPS مستقر کنید. برای چت‌جی‌پی‌تی وب یک Remote MCP Endpoint لازم است؛ اجرای صرفاً لوکال برای ChatGPT وب کافی نیست.

۲. در ChatGPT از بخش Plugins و گزینه `Add custom MCP server` (در صورتی که حساب شما این قابلیت را دارد) استفاده کنید؛ پروتکل Streamable HTTP را انتخاب کنید.

۳. آدرس را به صورت زیر وارد کنید و `No authentication` را انتخاب کنید:

```text
https://YOUR_DOMAIN/mcp/YOUR_LONG_MCP_ACCESS_PATH
```

**اخطار امنیتی:** مسیر شامل یک رمز دسترسی است؛ آن را در GitHub، لاگ‌ها یا اسکرین‌شات عمومی قرار ندهید. در صورت افشای آن، کلید را عوض کنید. مسیر ساده `/mcp` فقط با `Authorization: Bearer STUDIO_TOKEN` کار می‌کند و مناسب کلاینت‌های پشتیبان هدر است. این راهکار URL-capability برای آزمایش شخصی است، نه جایگزین OAuth در سرویس عمومی.

۴. مثال گفت‌وگو در ChatGPT:

> یک ویدیوی معرفی ۱۵ ثانیه‌ای برای «رواج» طراحی کن. سه صحنه، فارسی، حالت portrait، رنگ‌های آبی و سفید. ابتدا سناریو را پیشنهاد بده، بعد با `create_storyboard` ثبت کن. در صورت تأیید من `render_video` را اجرا کن و با `video_status` لینک MP4 را بده.

## مشخصات MCP

درخواست‌ها از نوع JSON-RPC 2.0 روی `POST /mcp` (Bearer auth)، یا `POST /mcp/{MCP_ACCESS_PATH}` (مسیر محرمانه) است. پاسخ‌ها JSON و به‌شکل stateless هستند. `initialize`, `ping`, `tools/list`, `tools/call` پشتیبانی می‌شوند؛ SSE و long-running sessions پشتیبانی نمی‌شوند. هنگام اتصال کلاینت‌های MCP ممکن است به تغییرات سازگاری نیاز باشد.

- `create_storyboard`: کل متن، زمان‌بندی و قالب را ذخیره می‌کند و شناسه ویدیو را برمی‌گرداند.
- `revise_storyboard`: کل استوری‌بورد را جایگزین می‌کند.
- `render_video`: رندر غیرهم‌زمان را آغاز می‌کند؛ فراخوانی بلافاصله تمام می‌شود.
- `video_status`: وضعیت و در صورت موفقیت آدرس امضاشده MP4/PNG را برمی‌گرداند.
- `list_videos`: فهرست مختصر پروژه‌های اخیر را برمی‌گرداند.

## محدودیت‌های نسخه اول

**صدای گوینده، موسیقی، افزودن فایل رسانه، صحنه‌های تعاملی 3D، ویرایش ویدیوی آپلودی، ساخت خودکار صحنه با مدل تصویری، رندر توزیع‌شده و مدیریت چندکاربره هنوز پیاده‌سازی نشده‌اند.** هیچ ادعایی مبنی بر تولید صدا یا ویدیوی واقع‌گرایانه وجود ندارد. رندرها به‌صورت محلی ساخته می‌شوند و پس از راه‌اندازی مجدد، صف در حافظه بازیابی نمی‌شود.

سرویس فاقد احراز هویت OAuth برای هر کاربر است. آن را بدون کنترل دسترسی، محدودسازی شبکه و سهمیه‌بندی در معرض استفاده عمومی قرار ندهید.
