# راهنمای کار با ChatGPT

## روش اول: اتصال مستقیم MCP (در حساب‌های دارای امکان اتصال)

طبق [راهنمای رسمی OpenAI](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)، در نوامبر ۲۰۲۶ امکان اتصال سفارشی با ابزارهای کامل برای Business و Enterprise/Edu مستند شده است. امکان ساخت ابزار سفارشی با این سطح دسترسی را روی حساب Plus نباید قطعی فرض کرد.

۱. پروژه را با [راهنمای سرور مستقل](SELF_HOST_FA.md) اجرا کنید و `https://YOUR_DOMAIN/health` را بررسی کنید.

۲. از بخش **Plugins** در ChatGPT، اگر گزینه `Add custom MCP server` در دسترس بود، نام `Chat Video Studio` و آدرس کامل محرمانه `https://YOUR_DOMAIN/mcp/YOUR_MCP_ACCESS_PATH` را وارد کنید.

۳. برای **نمونه تک‌کاربره** گزینه `No authentication` را انتخاب کنید؛ این گزینه فقط به این دلیل قابل استفاده است که رمز در مسیر تصادفی نهفته است. در ابزارهای چندکاربره **به OAuth مهاجرت کنید**.

۴. از چت بخواهید:

> یک ویدیوی ۱۵ ثانیه‌ای فارسی برای معرفی رواج بساز. ابتدا متن و زمان‌بندی سه صحنه را پیشنهاد بده و تأیید بگیر. بعد با create_storyboard سناریو را ذخیره کن. با render_video خروجی MP4 بساز. در پایان با video_status لینک دانلود و تصویر پیش‌نمایش را ارائه کن.

**ابزارها:** `create_storyboard` (ساخت)، `get_storyboard` (مطالعه سناریو)، `revise_storyboard` (اصلاح همه صحنه‌ها)، `render_video` (ارسال به صف)، `video_status` (وضعیت و دانلود)، `list_videos` (فهرست).

هر بار که تعریف ابزارها در سرور عوض شود، ممکن است نیاز باشد اتصال در ChatGPT **Refresh** شود. تأیید اقدامات نیز مطابق سیاست‌های خود ChatGPT ممکن است نمایش داده شود و از داخل این سرویس قابل حذف اجباری نیست.

## روش دوم: اگر اتصال MCP در حساب ChatGPT فعال نباشد

این روش **هیچ سروری نمی‌خواهد** و حتی با حسابی که اجازه سرور سفارشی ندارد کار می‌کند. در ChatGPT بگویید:

> برای من یک ویدیوی معرفی ۱۵ ثانیه‌ای فارسی طراحی کن. خروجی را فقط JSON با ساختار نمونه `examples/ravaj-intro.json` بده. `format` را portrait، `title` نام ویدیو، و `scenes` را شامل title، subtitle، duration، theme، visual و accent قرار بده. هر صحنه ۲ تا ۱۲ ثانیه و مجموع کمتر از ۶۰ ثانیه باشد.

JSON را در فایلی به نام `my-video.json` ذخیره کنید، سپس روی کامپیوتری که FFmpeg/Pillow نصب است:

```bash
npm run doctor
npm run render:local -- my-video.json my-video.mp4
```

خروجی `my-video.mp4` و `my-video-preview.png` ایجاد می‌شوند. هر اصلاحی را مجدداً از ChatGPT به‌صورت JSON بگیرید و فرمان را تکرار کنید. در این حالت ارسال فرمان و رندر از داخل چت **خودکار نیست**؛ اجرای محلی یا یک ابزار واسط لازم است.

### مثال JSON

```json
{
  "title": "معرفی رواج",
  "format": "portrait",
  "scenes": [
    {"title": "ایده‌های تازه", "subtitle": "محصولات دیجیتال ایران را کشف کن", "duration": 4, "theme": "midnight", "visual": "headline", "accent": "#22D3EE"},
    {"title": "رواج", "subtitle": "مرجع کشف محصولات ایرانی", "duration": 4, "theme": "light", "visual": "product", "accent": "#2563EB"}
  ]
}
```

## خروجی فعلی چه نوع ویدیویی است؟

تیتر، متن، رنگ‌بندی، بک‌گراند، المان‌های UI ساختگی و حرکت ملایم دوربین. در حال حاضر صدای گوینده، موسیقی، ویدیوی فیلم‌برداری‌شده، صحنه‌های سینمایی و تبدیل مستقیم متن به تصویر واقعی پشتیبانی نمی‌شوند.
